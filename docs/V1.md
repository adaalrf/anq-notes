# v1 scope

This release is a cloneable static publication with typed configuration, Markdown
posts, Markdown/HTML pages, YAML metadata, drafts, topics, pagination, RSS, sitemap,
robots/404 output, local assets, a token-based theme and a loopback preview.
The generated default site has no client JavaScript requirement.

It includes content/output validation, internal file/fragment checks, HTML
sanitization, previous-output preservation, deterministic file contents and
production static-container packaging. These are tested against local files and
browsers, and the disposable Ubuntu deployment passed the same browser checks.
See [deployment evidence](DEPLOYMENT.md); no production availability claim is made.

Deferred: npm-distributed CLI, plugin framework, client themes/search, comments,
authentication, scheduling, incremental/watch builds, localization, nested content
folders, URL-prefix hosting and external-link crawling. Avoid expanding this
scope while the other selected portfolio projects still need their v1 work.
