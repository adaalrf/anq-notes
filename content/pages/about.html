--- title: About this notebook. description: A small static site, made to be understood and changed. ---

ANQ Notes is a fictional starter notebook. It demonstrates a cloneable static site generator, rather than representing a live publication.

How it works

Write Markdown or an HTML page, run a build, and deploy the generated files. The visitor needs neither JavaScript nor an account.

The source keeps content, presentation, and build code in separate folders. Read the getting-started note for a tour.
